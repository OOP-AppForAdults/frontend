# 성인을 위한 필수 상식 가이드 프로그램 (Frontend)

기초 예절 및 사회 상식을 학습할 수 있는 데스크톱 애플리케이션의 프론트엔드 리포지토리입니다. 사지선다형 퀴즈와 카드 분류 게임의 사용자 인터페이스(UI)를 구현하고, 백엔드와 연동하여 사용자의 학습 이력을 시각적으로 제공합니다.

```text
